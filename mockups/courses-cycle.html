What is not working now

Three things. The band is 88px on a 400 box, which reads as a soft donut rather than anything architectural. Round caps on a stroke that thick turn the overlaps into amoeba shapes. And because the labels orbit, you never see Learn, Apply, Reflect, Refine in order — the sequence, which is the entire point, is only legible for a moment every 40 seconds.

A — thin track, one travelling marker

The ring goes back to a hairline and the colour becomes four quiet arc tints behind it. Labels stay put, so the order always reads. The only motion is a single dot completing a lap every 26 seconds, plus an almost invisible breath in the ring. Precise and architectural; the movement is a cue, not the subject.

B — a spiral, not a loop

A circle says you end where you started. A spiral says you come back to the same four questions further out than last time, which is the actual argument for a cycle and the thing "Again, better" was reaching for. It draws itself once on load and then holds — no perpetual motion at all.

C — four sheets in a cycle

The literal sibling of the Expertise hero: the same hand-cut tinted sheets, arranged as a cycle with a hairline path running between them. Nothing rotates; each sheet drifts a few pixels on its own slow loop, exactly like the Expertise sheets. Strongest family resemblance of the four.

D — a track that runs and returns

Reads left to right, so the order is unmissable — the one thing a ring can never do. The return curve underneath carries the repeat. A marker steps through the four stages and loops back every fourteen seconds. Least decorative, clearest.
